# Bea Luxe NG — Lifestyle Store

> **"Everyday pieces, elevated."**  
> Luxury unisex wears, footwear, bags, perfumes, fashion accessories, kitchen items, and household essentials.

---

## ✦ Overview
Bea Luxe NG is a mobile-first, editorial lifestyle eCommerce showcase for a luxury retail brand based in Lagos, Nigeria. The design is inspired by high-end boutique stores with clean typography, warm natural palettes (deep forest green, cream, soft beige, muted gold), smooth scroll animations, and pre-filled WhatsApp concierge ordering.

## ✦ Features
- **Editorial Aesthetic:** Built with the exact boutique layout of Base44 / luxury retail design.
- **7 Lifestyle Categories:**
  1. Unisex Wears
  2. Footwear
  3. Bags
  4. Perfumes
  5. Fashion Accessories
  6. Kitchen Items
  7. Household Items
- **Interactive Catalogue:** Filter by category, search by product name/description, and view availability states (*In Stock*, *Price on request*, *Sold out*).
- **Direct WhatsApp Commerce:** Every product card and contact action links directly to WhatsApp with pre-filled product enquiries (`+2348162040699` / `+2348159495250`).
- **Interactive Elements:**
  - Ribbed deep forest hero banner with warm cutout photography
  - Category 8-tile overview grid
  - Micro-interactions, hover zoom effects, and scroll reveals
  - Responsive mobile drawer and floating WhatsApp action pill

## ✦ Tech Stack
- **HTML5:** Semantic, accessible markup
- **CSS3:** Custom luxury design system, responsive breakpoints, smooth cubic-bezier transitions
- **Vanilla JavaScript:** Fast client-side filtering, live search, and dynamic URL message composition

## ✦ Getting Started
Open `index.html` in any modern web browser or serve locally:
```bash
python -m http.server 8000
# or
npx serve
```
Visit `http://localhost:8000`.
